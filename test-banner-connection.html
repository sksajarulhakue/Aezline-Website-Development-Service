Test Banner Connection

This page demonstrates how the admin banner manager is connected to the main website through localStorage.

Follow these steps to test the connection:

  1. Open the admin banner manager and make changes to banners (upload, edit, or delete)
  2. Make sure to mark banners as "Active" if you want them to appear on the website
  3. Open the main website to see your changes
  4. Use the buttons below to view the current banner data in localStorage
